# TrustHouse and Alliance proposal site

Static site. No build step, no framework, no external requests. Live: https://trusthouse-lead-routing-proposal.vercel.app

## Clone and preview

```bash
git clone https://github.com/echang-afk/trusthouse-lead-routing-proposal.git
cd trusthouse-lead-routing-proposal
python -m http.server 8000
# open http://localhost:8000
```

Use a local server, not a double-click on `index.html`: the diagram frames size themselves from the diagram's height, and the browser blocks that for `file://` pages (the frames then keep a fixed height).

## Layout

| Path | What it is |
|---|---|
| `index.html` | The English page. All CSS and JS are inline. This file is the source of truth: it was edited directly, so edit it directly. |
| `diagrams/*.html` | The three diagrams (`before`, `after`, `lead-journey`). Generated by the Archify skill, about 800 KB each, self-contained. Do not hand-edit; regenerate from `src/`. |
| `src/*.json` | Archify specs for the diagrams. These are the real source of the diagrams. |
| `vercel.json` | Clean URLs plus `X-Robots-Tag: noindex` and two safe headers. |
| `zh/` | The Chinese copy of the page, its diagrams and specs. Not deployed, no link points to it. |

## Change a diagram

```bash
cd C:/Users/Ewan/.claude/skills/archify
node bin/archify.mjs validate architecture <proposal-site>/src/before.architecture.json --quality showcase --json
node bin/archify.mjs deliver  architecture <proposal-site>/src/before.architecture.json <proposal-site>/diagrams/before.html --quality showcase --json
```

Use `sequence` instead of `architecture` for `lead-journey`. Diagram frames on the page size themselves to the diagram (`iframe.fit`, script at the bottom of `index.html`), so a taller diagram needs no page change.

## Deploy

Copy `index.html`, `diagrams/` and `vercel.json` into a clean folder (leave out `zh/` and `src/`), then:

```bash
vercel deploy --prod --yes --scope <your-vercel-team>
```

Take it down: `vercel remove trusthouse-lead-routing-proposal --scope <your-vercel-team>`.

## Things to know

- Dark/light toggle: the page stores `th-theme` and also writes `archify-theme`, the key the diagrams read, so both follow one switch.
- The Answer blocks and sections 1 to 7 were generated by scratch scripts and then edited by hand. Those scripts are not in this folder and have drifted from the HTML, so do not try to re-run them. Edit `index.html`.
- The page shows staff first names (Bob, Kaitlyn, Alyssa, Jennifer) on a public URL.
